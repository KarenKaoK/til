# Open Slide

## Simple Introduction

- Open Slide is a tool for creating presentations in a more code-based way.

- Unlike PowerPoint, where you can drag and adjust objects directly with a mouse, Open Slide treats each slide as a React component.

- It is usually used with coding agents such as Codex or Claude, which makes it easier to generate presentations using natural language.

## Workflow

- Human gives a brief.

- Agent creates the presentation.

- Human reviews it.

- Human writes prompts to adjust or improve it.

- Repeat the process.

## Benefits

- It can generate presentations more efficiently using natural language.

- Since it is based on React and web technologies, the layout, animation, and interaction can be more flexible.

- Users can focus more on the content, storyline, brief, and review process.

## Drawbacks

- Small layout adjustments are not as direct or easy as in PowerPoint.

- AI-generated results may not always meet human expectations, so it still takes time to review and adjust them.

- If you need a highly editable `.pptx` file, PowerPoint is still more convenient.
