# spec-driven-development-tools

## Popular SDD Tools

[Spec-Driven Development (SDD)](./spec-driven-development.md) is an approach that defines requirements, specifications, and acceptance criteria before implementation, helping AI coding agents better understand development goals and reduce unnecessary rework.



Three popular tools for spec-driven development are:

- [GitHub Spec Kit](https://github.com/github/spec-kit) — An open-source toolkit that provides a structured development workflow, from specification and technical planning to task breakdown and implementation.

- [OpenSpec](https://github.com/openspec) — A lightweight, flexible specification framework that focuses on incremental changes and continuous development, particularly for existing codebases.

- [Kiro](https://aws.amazon.com/kiro/) — An AI-powered development environment from AWS that integrates specification writing, technical design, task management, and implementation into a single workflow.

## 2. Tool Comparison

| Aspect | GitHub Spec Kit | OpenSpec | Kiro |
|---|---|---|---|
| Tool Type | Open-source toolkit | Open-source framework | AI-powered IDE & CLI |
| Core Philosophy | Structured specification and planning | Incremental changes and living specifications | Integrated AI development workflow |
| Workflow | Specify → Plan → Tasks → Implement → Converge | Propose → Apply → Archive | Requirements → Design → Tasks → Implement |
| Process Complexity | High | Low to Medium | Medium |
| Documentation Overhead | High | Low to Medium | Medium |
| Flexibility | Structured workflow | Flexible workflow | Integrated workflow |
| Agent Compatibility | Multiple coding agents | Multiple coding agents | Kiro ecosystem |
| Main Advantage | Comprehensive planning and traceability | Efficient change management | Seamless development experience |
| Main Limitation | Higher planning and documentation overhead | Less prescriptive project planning | Platform dependency |
| Best Use Case | Complex or greenfield projects | Existing projects and continuous iteration | Developers seeking an integrated AI development environment |
| Cost | Free and open-source | Free and open-source | Free and paid plans |

## Key Differences

- **Spec Kit** focuses on defining what to build and how to build it through a structured planning process.
- **OpenSpec** focuses on managing what needs to change while maintaining existing specifications.
- **Kiro** focuses on integrating spec-driven development directly into the AI development environment.

Both Spec Kit and OpenSpec can be used with existing coding agents such as Claude Code, while Kiro provides its own integrated development experience.
